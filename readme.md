# การจำแนกชนิดการมอดูเลตสัญญาณวิทยุอัตโนมัติ

**Automatic Modulation Classification on RadioML 2016.10A**

Final Assignment วิชา Mathematics for Data Science (01236252) | กำหนดส่ง 16 พฤศจิกายน 2569

## โปรเจกต์นี้ทำอะไร

สอนคอมพิวเตอร์ให้ดูสัญญาณวิทยุแล้วบอกได้ว่าเป็นการมอดูเลตแบบไหน และเปรียบเทียบสองแนวทาง

- ให้โมเดลเรียนจากสัญญาณดิบ โดยลดมิติด้วย PCA
- ให้โมเดลเรียนจาก feature ที่ออกแบบจากความรู้ด้าน Communication

นี่เป็นโปรเจกต์ด้าน Data ชิ้นแรกของเจ้าของโปรเจกต์ จึงตั้งใจเรียนรู้ทีละขั้นและบันทึกการเรียนรู้ไว้ด้วย
